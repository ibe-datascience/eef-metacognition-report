# Semi-automated evidence synthesis in education

Analytical report (working draft) by the Data Science Team of the Educational Research Institute — National Research Institute (IBE PIB), Warsaw: reproducing the EEF Toolkit strand *Metacognition and self-regulation* with large language models.

- English: https://ibe-datascience.github.io/eef-metacognition-report/en.html
- Polski: https://ibe-datascience.github.io/eef-metacognition-report/pl.html

The HTML files are self-contained (Quarto, `embed-resources: true`). Source files are kept in the internal pipeline repository.
